# 公众号 AI Studio 2.1.3 综合整改与验证报告

## 1. 版本定位

2.1.3 是在 2.1.2 审计修复候选版上的持续整改版本，重点不是重复修补 P0，而是把仍停留在“工具缺失、验证脚本不可执行、容量只做边界测试”的项目补成可使用、可执行、可复核的交付能力。

版本定级：**Release Candidate**。

## 2. 功能变化

### 2.1 万级文章中心

- 后端项目查询增加关键词 `q`、`total`、`hasMore`、回收站精确过滤。
- 排序增加 `id` 次级排序，避免相同时间戳分页不稳定。
- Bootstrap 只加载首批 50 篇，并提供活动、全部、回收站数量。
- 前端文章中心按 50 篇分页，搜索、归档、回收站切换都重新从服务端查询。
- 复制、归档、删除、恢复、永久删除后重新加载当前页并更新总数。

### 2.2 真实外部验证

- AI 验证修复 `draft(goal, evidence, plan, target_length)` 调用。
- AI 结果记录框架项数、正文字符数、正文 SHA-256 和审校状态集合。
- 微信验证可直接读取本地封面文件，按文件签名确认 PNG/JPEG/GIF/WEBP。
- 通过 `material/add_material` 上传真实永久图片素材，再使用返回的 `media_id` 调用 `draft/add`。
- 输出不记录 Key、AppSecret、access token；可通过 `STUDIO_VERIFY_WECHAT_CLEANUP=1` 请求删除测试草稿和新上传素材。

### 2.3 平台实机验收

- `verify_windows_dpapi.py/.cmd`：验证 2.1.1 原始 32 字节主密钥升级、同用户重启解密、新建 DPAPI 密钥和密文篡改拒绝。
- `verify_browser_service.py/.cmd`：不启用测试适配器，使用真实 HTTP 服务和预置 SQLite 文章，验证分页、工作区、自动保存、服务端预览、人工终审和版本历史。
- `verify_capacity.py`：真实 10,000 篇文章、随机分页、检索、100 次连续编辑和 SQLite 完整性。

## 4. 使用命令

```bash
python test_all.py
python verify_capacity.py
python verify_external_links.py
python verify_browser_service.py
python verify_windows_dpapi.py
```

Windows 可直接运行：

```text
verify_browser_service.cmd
verify_windows_dpapi.cmd
```
